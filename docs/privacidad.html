Política de privacidad de AVD time

Última actualización: 9 de noviembre de 2026

AVD time es un temporizador de intervalos para entrenamiento creado por AVD · Entrenamiento físico deportivo. Esta política explica qué datos usa la app.

Datos que guarda la app

Los programas de entrenamiento, las 20 memorias, el historial de sesiones y los ajustes de sonido se guardan solo en tu teléfono. No se envían a ningún servidor ni a AVD.

Datos que recogemos

Ninguno. AVD time no tiene cuentas de usuario, publicidad, analítica ni rastreo, y no comparte datos con terceros.

Conexión a internet

La versión descargada desde GitHub consulta, como máximo cada 3 horas, el archivo público de la última versión en GitHub para avisarte si hay una actualización. Esa consulta no incluye ningún dato tuyo. La versión de Google Play no usa internet.

Permisos

  • Vibración: para avisar los cambios de intervalo.
  • Mantener la pantalla encendida: mientras el temporizador está en marcha.
  • Internet e instalar paquetes (solo versión de GitHub): para descargar e instalar actualizaciones cuando tú lo confirmas.

Borrar tus datos

Puedes borrar el historial desde la pestaña Historial, o todos los datos desinstalando la app o borrando sus datos en Ajustes de Android.

Contacto

Para preguntas sobre esta política, abre una consulta en github.com/adrianvillarroeldelgado-max/AVD-TIME/issues.
