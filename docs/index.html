Instalar

  1. Pulsa Descargar APK desde el teléfono Android.
  2. Abre el archivo descargado. Si aparece un aviso, permite Instalar apps desconocidas para tu navegador.
  3. Pulsa Instalar. Las versiones nuevas se avisan dentro de la app y se instalan encima: tus programas e historial se conservan.
